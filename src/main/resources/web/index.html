Hilfe bei Problemen

Falls das MediPot.jar nicht startet:

  • ZIP-Version nutzen: Wenn das JAR-File nicht ausführbar ist oder eine Java Runtime Exception auftritt, laden Sie bitte die ZIP-Alternative herunter und starten sie das run.bat

Falls die Datenbank veraltet ist:

  • Löschen Sie die Datei medipot.db im Benutzerordner:
  • Windows: C:\Users\[Benutzername]\.medipot
  • Linux/macOS: /home/[Benutzername]/.medipot

Die Datei wird beim nächsten Start automatisch neu erstellt.
